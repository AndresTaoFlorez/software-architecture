# Design Patterns

A pattern describes a recurring design problem and a useful arrangement of responsibilities. Start with the problem you have, then choose the relevant explanation.

- [Presentation](presentation/README.md): MVC and MVVM organize screen interaction.
- [Persistence](persistence/README.md): Repository separates stored objects from data access.
- [Structural](structural/README.md): Facade simplifies using collaborators.

Read the [common learning route](../README.md) before treating a pattern as a required piece.
