# GitHub Copilot — Application Project

Follow the application's root `AGENTS.md` as the engineering policy. Read it before proposing or editing code if it was not loaded automatically.

Inspect the application's current requirements, ADRs, callers, contracts and tests. Find the handbook location and reviewed revision in the application's `AGENTS.md`. Open its `README.md` and only the pages relevant to the task if that source is accessible in this Copilot session. A cloud session cannot use a sibling checkout that exists only on a developer's machine. Record the revision actually read. The handbook is **design guidance**, not an override of approved application decisions.

Make proportionate changes, preserve compatibility and run the application's real checks. Report actual evidence and any unavailable files, tools or tests.

This file is an **optional adapter for Copilot surfaces that load `.github/copilot-instructions.md`**. Put it at that path in the **application repository**, not this handbook. Support for `AGENTS.md` differs by Copilot surface and mode. If the application already has a Copilot instructions file, integrate this small bridge without erasing project rules. Verify the active instruction files in the chosen surface.
