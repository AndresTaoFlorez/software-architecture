# GitHub Copilot — Application Project

Follow the application's root `AGENTS.md` as the engineering policy. Read it before proposing or editing code if it was not loaded automatically.

Inspect the application's current requirements, ADRs, callers, contracts and tests. Consult `../software-architecture/README.md` and only the handbook pages relevant to the task, if that checkout is accessible. Record the handbook revision actually read. The handbook is **design guidance**, not an override of approved application decisions.

Make proportionate changes, preserve compatibility and run the application's real checks. Report actual evidence and any unavailable files, tools or tests.

This file is an **optional adapter for Copilot surfaces that load `.github/copilot-instructions.md`**. Put it at that path in the **application repository**, not this handbook. Other Copilot modes can load `AGENTS.md` directly; capabilities differ by IDE and mode. If the application already has a Copilot instructions file, integrate this small bridge without erasing project rules.
