# Extras

Architecture determines responsibilities, dependencies and supported interactions. Adjacent disciplines answer their own questions about concurrency, distributed consistency, security, performance or operations.

Material belongs here when it warrants an independent, source-backed guide with a concrete problem and sufficient explanation. A passing mention in an architecture chapter is not that guide.

There are no topic guides yet. Core exercises stay focused on architectural reasoning; future additions should follow the [same editorial standard](../CONTRIBUTING.md).
